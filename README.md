# 🤖 SmartGPT

An AI-powered chatbot web application built using the MERN stack and OpenAI API.  
SmartGPT allows users to securely log in, interact with AI in real-time, manage multiple conversation threads, and revisit previous chats seamlessly.

## 🚀 Live Demo
🔗 https://mysmartgpt.onrender.com/ 

---

## 📌 Features

- 🔐 Google OAuth Authentication
- 🛡 Secure session management
- 💬 Real-time AI chat using OpenAI API
- 🧵 Multiple conversation threads
- 💾 Persistent chat history (MongoDB)
- 📱 Fully responsive React UI
- ⚡ Production-ready deployment

---

## 🛠 Tech Stack

**Frontend:**
- React.js
- Context API / State Management
- Axios
- CSS / Tailwind 

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT / Session-based authentication
- OpenAI API

**Authentication:**
- Google OAuth 2.0

---

## 🧠 How It Works

1. Users log in securely using Google OAuth.
2. After authentication, a session is created and stored securely.
3. Users can:
   - Start a new chat thread
   - Continue previous conversations
   - Switch between multiple threads
4. Messages are sent to the OpenAI API.
5. AI responses are stored in MongoDB for future retrieval.
